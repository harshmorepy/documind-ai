## 🎯 Why DocuMind AI?

Traditional chatbots cannot reliably answer questions about private
documents because they lack access to the document's content.

DocuMind AI combines Retrieval-Augmented Generation (RAG), vector
embeddings, ChromaDB, FastAPI and Gemini to produce grounded,
document-aware answers with source citations.
