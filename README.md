# 📚 DocuMind AI

An AI-powered document assistant that allows users to upload PDF documents and ask natural language questions using Retrieval-Augmented Generation (RAG).

---

## 🚀 Features

- Upload PDF documents
- Ask questions about uploaded documents
- AI-generated answers
- Source-aware responses
- Clean Streamlit interface

---

## 🛠️ Tech Stack

- Python
- FastAPI
- Streamlit
- LangChain
- ChromaDB
- Google Gemini
- Git & GitHub
